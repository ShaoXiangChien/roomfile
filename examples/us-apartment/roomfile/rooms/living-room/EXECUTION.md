# Phased execution

1. Re-measure the sofa, table, entry swing, radiator clearance, and delivery path.
2. Tape the coffee-table footprint on the floor for 24 hours; confirm walking clearance.
3. Re-check IKEA article numbers, current price, package size, return policy, and delivery to a real user-supplied ZIP.
4. Buy one phase at a time. Assemble the coffee table before adding small decor.
5. Place the floor lamp, then adjust the sofa-side vignette without drilling.
6. Add removable art, textiles, and plants only after the main scale feels right.
7. Photograph the result from the canonical viewpoint and compare it with the approved brief—not with the render alone.

No structural, electrical, permanent built-in, contractor, checkout, or purchasing action is part of this plan.
