# Roomfile v0.3.0

Roomfile v0.3.0 adds the Hybrid Style Atlas and `$roomfile style`, connecting
evidence-first taste work to researched field guides, structured design
signals, rights-verified visual references, and sourced live-research
fallbacks.

The release also adds project schema `0.3.0`, idempotent migration from v0.2,
public editorial Atlas pages, and a controlled same-room rendering benchmark.
Mid-century Modern, Bauhaus, and Japandi are the first complete field guides;
they are examples, not a supported-style boundary.

Read the complete changelog, image-license methodology, compatibility notes,
benchmark caveat, install command, and verification summary in
[RELEASE_NOTES_v0.3.0.md](../../RELEASE_NOTES_v0.3.0.md).
