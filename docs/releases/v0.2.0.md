# Roomfile v0.2.0

Roomfile now treats interior design as one continuous collaboration—from
understanding the room to placing and sourcing the pieces that make the design
real.

## What changed

- Reframed the public experience around **Design your home, together.**
- Rebuilt the website as an editorial room journey rather than a feature
  catalog.
- Added one evolving Mid-century Modern living-room story, an annotated product
  ledger, a Bauhaus workspace story, and a Japandi bedroom story.
- Added keyboard-accessible design revisions and synchronized product pins.
- Added preference-first setup and sourcing. Roomfile now records location,
  currency, units, delivery area, preferred retailers, and retailer strategy
  before searching.
- Added schema `0.2.0`, three-letter ISO product currencies, explicit profile
  status, and an idempotent `0.1.0 → 0.2.0` migration.
- Kept `0.1.0` validation compatibility with an upgrade warning.
- Added Chrome desktop/mobile E2E coverage for public routes, overflow,
  navigation, copy controls, revisions, product pins, reduced motion, and the
  legacy canonical route.
- Refreshed the README, launch card, repository preview, and two five-slide
  social carousels.

## Upgrade an existing project

```bash
node skills/roomfile/scripts/migrate-project.mjs \
  --project /absolute/path/to/roomfile \
  --to 0.2.0 \
  --json
```

Migration preserves existing location, products, photos, prices, and decisions.
It is safe to run more than once.

## Install
