# Roomfile v0.1.1

Released 2026-07-18.

## What changed

- Repositioned Roomfile for any room, region, and style. Region, currency,
  units, postal-code conventions, and retailer priority remain project settings.
- Clarified that Roomfile derives three directions by default and does not use
  a fixed style catalog. Mid-century Modern, Bauhaus, and Japandi are examples,
  not presets.
- Added `/examples/apartment` as the canonical fictional case study while
  retaining `/examples/us-apartment` as a compatibility route.
- Corrected the selected example to **Eclectic Mid-century Modern**, with amber
  layered lighting, walnut, olive, rust, tactile textiles, a graphic 1970s rug,
  records, books, posters, and plants.
- Regenerated the exploration, approved refinement, and IKEA placement through
  Banana using `gemini-3.1-flash-image` at 2K. Image-output cost for this
  revision was estimated and recorded at US$0.303.
- Refreshed the website, README hero, Open Graph card, repository preview,
  social carousels, launch copy, and accessible alt text.

## Compatibility

Project schema version remains `0.1.0`; existing projects and deterministic
script interfaces are unchanged.
